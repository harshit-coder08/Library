# Library

A simple book library app built for The Odin Project. Add books through a form, see them as cards, and manage them from the page.

## Features

- Add a book with its title, author, number of pages, and read status
- View all books as cards on the page
- Remove a book from the library
- Toggle a book between read and not read

## Built With

- HTML
- CSS (grid and flexbox)
- JavaScript

## What I Practised

- Object constructors and `Book.prototype`
- Storing objects in an array
- DOM manipulation: creating elements, appending them, and clearing and redrawing the page
- Handling form submission and click events
- Using unique ids to find and remove the right book

## How to Run

Download or clone the repository and open `index.html` in your browser.
